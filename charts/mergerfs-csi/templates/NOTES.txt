1. Install chart:

   helm install mergerfs-csi {{ .Chart.Name }} \
     --namespace kube-system \
     --set image.repository={{ .Values.image.repository }} \
     --set image.tag={{ .Values.image.tag }}

2. Image bakes mergerfs from GitHub releases (see Dockerfile `MERGEFS_VERSION`, Renovate-managed).

   docker build --platform=linux/amd64 -t {{ .Values.image.repository }}:{{ .Values.image.tag }} .

3. Driver name: {{ .Values.driver.name }}

4. CSIDriver: attachRequired=false, podInfoOnMount=true, fsGroupPolicy=None.

5. Examples: examples/static-pv-hostpath.yaml, layered-pvc-emptydir.yaml, layered-rclone.yaml

6. Verify:

   kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/name={{ include "mergerfs-csi.name" . }}
