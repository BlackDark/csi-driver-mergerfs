1. Install chart:

   helm install mergerfs-csi {{ .Chart.Name }} \
     --namespace kube-system \
     --set image.repository={{ .Values.image.repository }} \
     --set image.tag={{ .Values.image.tag }}

2. Image must include mergerfs binary. Build with:

   docker build --build-arg MERGEFS_URL=<upstream-static-tarball-url> -t {{ .Values.image.repository }}:{{ .Values.image.tag }} .

3. Driver name: {{ .Values.driver.name }}

4. CSIDriver uses attachRequired=false, podInfoOnMount=true, fsGroupPolicy=None.

5. Static PV examples: see examples/static-pv-hostpath.yaml and examples/layered-pvc-emptydir.yaml

6. Verify node plugin pods:

   kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/name={{ include "mergerfs-csi.name" . }}
